# ru-website-legal

Скилл для юридической подготовки сайтов по праву России. Он осматривает сайт, выясняет недостающие факты о бизнесе и сервисах, определяет применимые требования, готовит проекты документов для проверки юристом и показывает, что ещё нужно сделать владельцу и разработчику.

## Что в комплекте

- [`ru-website-legal/SKILL.md`](ru-website-legal/SKILL.md) — маршрут работы и границы применения.
- `ru-website-legal/references/legal-workflow/` — осмотр, интервью, решения, документы и проверка внедрения.
- `ru-website-legal/references/legal-research/` — правовые досье, источники, открытые вопросы и порядок актуализации.
- `ru-website-legal/agents/openai.yaml` — отображение скилла в Codex.

Нужна **вся папка `ru-website-legal`**: один `SKILL.md` ссылается на остальные файлы.

## Как использовать в Codex

Скопируйте папку `ru-website-legal` целиком в `~/.codex/skills/`. Затем начните чат с запросом, например:

> Используй $ru-website-legal для сайта [адрес]. Сначала осмотри сайт и задай вопросы, без которых нельзя определить нужные документы и действия.

Если скилл добавлен во время открытого чата и не появился, начните новый чат. [Документация OpenAI о расположении скиллов](https://developers.openai.com/blog/eval-skills).

## Границы результата

- Исследовательский срез правовой базы сделан **17.09.2026**; отдельные федеральные акты точечно сверены **27.09.2026**. Даты проверки, источники и нерешённые вопросы записаны в [`06-verification-log.md`](ru-website-legal/references/legal-research/06-verification-log.md). Перед применением к конкретному сайту нужно проверить актуальность затронутых норм и фактические настройки сайта.
- Скилл не подставляет неизвестные реквизиты и процессы. Если данных не хватает, он задаёт вопросы и отмечает ограничения результата.
- Подготовленные тексты предназначены **для проверки юристом**. Их создание не означает, что юрист их проверил, документы размещены или работа сайта соответствует требованиям.
- Исследовательские файлы сохраняют историю подготовки скилла; фразы в них о будущем создании скилла относятся к тому этапу работы.

Публикация документов, изменение работающего сайта и отправка уведомлений выполняются только по отдельному поручению.
